# web_app_admin

`web_app_admin` is the administrative frontend for managing the `our_places_rs` villa booking system. It is built using the [Leptos](https://github.com/leptos-rs/leptos) web framework, compiled to WebAssembly (Wasm).

This application allows administrators to manage listings, users, bookings, and other core aspects of the platform.

## Running your project

`cargo leptos watch`
By default, you can access your local project at `http://localhost:3000` (Note: Ensure ports do not conflict with the main `web_app`).
